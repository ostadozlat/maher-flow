# ماهر فلو (Maher Flow) — V1

نسخه MVP برای مدیریت کارگاه‌های برق، الکترونیک و اتوماسیون.

## تکنولوژی
- PHP 8.1+
- MySQL 8 / MariaDB
- PDO
- Tailwind CSS CDN
- Chart.js CDN
- رابط RTL فارسی با Vazirmatn

## نصب روی هاست اشتراکی
1. یک دیتابیس MySQL و کاربر آن را در کنترل‌پنل هاست بسازید.
2. مقادیر `config/config.php` را با اطلاعات دیتابیس پر کنید.
3. کل پوشه را داخل `public_html` یا ساب‌دامین `flow.maherelec.ir` آپلود کنید.
4. آدرس `install.php` را یک‌بار باز کنید و حساب مدیر را بسازید.
5. بعد از نصب، فایل `install.php` را حذف کنید.
6. با `login.php` وارد شوید.

## ماژول‌های V1
- داشبورد
- سفارش‌های کاری
- ثبت سفارش
- مشتریان
- تجهیزات
- پروژه‌ها (ساختار دیتابیس آماده)
- انبار و قطعات

- Timeline سفارش
- پرداخت‌ها
- گزارش اولیه

## نکته
برای محیط واقعی، CDNهای Tailwind/Chart.js را می‌توان در نسخه بعدی self-host کرد. همچنین برای V2 بهتر است RBAC دقیق، آپلود امن فایل، بکاپ خودکار، فاکتور PDF، QR Code، مدیریت کامل پروژه/تجهیزات/قطعات و اتصال AI تکمیل شود.
